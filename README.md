# MoneyWise – Smart Expense Tracker

MoneyWise is a full-stack web application developed using the MERN stack to help users manage their personal finances.

## Features

- User registration and login
- Secure authentication
- Add and manage income and expenses
- Expense tracking
- Dashboard with financial information
- Daily and monthly expense views
- Expense filtering
- Statistics and financial insights
- Responsive user interface

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB
